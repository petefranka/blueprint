# decisions.md format

```markdown
# Decisions Log

## DEC-XXX: <Short title>

### Question
<the specific unresolved question>

### Evidence
<what the source material does and doesn't settle>

### Affects
<which feature(s) this blocks or changes>

### Status
Needs decision | Resolved
```

Something belongs here — not buried in a feature document as an
assumption — whenever it would change what users actually experience and
the source material doesn't settle it. Never invent an answer here.

On a re-run, don't delete resolved-looking entries. Mark them Resolved
and note what settled them.
