# Input: Multi-Feature Design

## Screen: Dashboard
Shows account balance, a list of recent transactions, and a "Send Money"
button.

## Screen: Send Money
Recipient picker, amount field, optional note, review step, confirm step.

## Screen: Transaction Detail
Shows one transaction: amount, date, recipient/sender, status, a "Report a
problem" link.

## Screen: Settings
Profile info, notification preferences, linked bank accounts, a "Log out"
button.
